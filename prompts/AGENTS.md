# SOC5 Outbound AI Instructions

## Project Goal

Modernize and improve the frontend UI while preserving all existing functionality.

## Mandatory Rules

- Never modify backend business logic unless explicitly requested.
- Never change API endpoints.
- Never change database schema.
- Never modify authentication flow.
- Never remove existing features.
- Keep all TypeScript types valid.
- Preserve React Router routes.
- Reuse existing components whenever possible.
- Prefer reusable components over duplicated code.
- Maintain responsive layouts.
- Preserve accessibility.
- Keep performance in mind.

## Frontend

Allowed:

- UI redesign
- Component extraction
- Styling improvements
- Responsive layouts
- Animations
- Icons
- Loading states
- Empty states
- Error states

Not Allowed:

- Backend modifications
- API contract changes
- Database changes
- Authentication changes

## Before Editing

Always:

1. Analyze the repository.
2. Explain the implementation plan.
3. Show affected files.
4. Wait for approval before making edits.
